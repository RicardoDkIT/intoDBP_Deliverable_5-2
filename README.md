# intoDBP_Deliverable_5-2
This repository contains Supplementary Material A for Deliverable 5.2, “Longer-term simulations of projected changes in lake DOM concentrations related to climate change.” It includes the GLM and AED configuration files for Lough Feeagh (Ireland) and Sau Reservoir (Spain), parameter sets, calibration and validation results and scripts used in the modelling workflow. These materials support the analyses presented in the deliverable and document the simulations of water temperature and dissolved organic carbon (DOC), used as an indicator of dissolved organic matter (DOM), under historical conditions and future climate scenarios.
